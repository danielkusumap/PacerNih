PacerNih — Panduan Aplikasi

Flow, use case, detail halaman & UI · applicationId com.daniel.runcoach minSdk 26 targetSdk 34

Deskriptif. Sumber kebenaran: RUNCOACH_PLAN.md (data/alur/rumus) dan DESIGN.md (tampilan).

1. Ringkasan

PacerNih adalah aplikasi lari offline, tanpa biaya yang:

  • melacak jarak, pace, dan waktu dari GPS;
  • menjalankan workout terstruktur dengan target pace + suara/beep;
  • memberi koreksi real-time dan auto-pause;
  • menyimpan riwayat, statistik mingguan, rekor pribadi;
  • export GPX dan cadangan/restore; 100% data lokal.

5.5 Gaya Grafik (CH1–CH6)

  • Latar transparan; garis bantu horizontal 1dp outline (maks 4); tanpa garis vertikal (kecuali batas segmen).
  • Batang: lebar 60% slot, sudut atas radius 4, aksen (terpilih) / aksen 35% (lainnya); nol = garis 2dp outline.
  • Garis: 3dp aksen ujung bulat; area gradien 18%→0%; null = garis putus.
  • Target (tangga) 2dp putus-putus textSecondary; batas segmen 1dp putus-putus outlineStrong.
  • Tooltip kartu surfaceRaised radius 12; muncul saat sentuh/seret.
  • Tinggi: CH1/CH6 200dp; CH2–CH5 160dp; animasi masuk sekali.

6. Detail Halaman S01–S15

S01 — Onboarding & Izin

Tujuan: memandu izin, satu keputusan per langkah.

Data: 4 langkah (indikator 4 titik; aktif = batang aksen 24×6dp): intro, izin lokasi, izin notifikasi, baterai. Status izin + banner.

Kontrol: primer (Berikan izin/Lanjut/Mulai), tersier (Lewati), sekunder (Buka pengaturan baterai).

UI: tanpa TopBar; lingkaran 112dp accentContainer + ikon 56dp accentText; judul titleL; penjelasan body textSecondary; status izin = ikon pass/fail + teks.

Navigasi: Mulai → set onboarding_done → S02.

S02 — Beranda (tab Latihan)

Data: banner "Lanjutkan sesi"; kartu Lari Bebas; ringkasan minggu ini (Jarak/Sesi/Selisih); daftar template (nama, strip, chip, Mulai, "terakhir dipakai").

Kontrol: Lari Bebas/Mulai → S04; ⋮ (Edit/Duplikat/Hapus); tombol mengambang Buat → S03; BottomBar.

UI: kartu Lari Bebas aksen penuh tinggi 96dp radius 20; tombol Buat = pil radius 18 (bukan FAB bulat).

State: loading skeleton; kosong → EmptyState + "Buat workout pertama".

S03 — Editor Workout

Data: nama + target jarak; bar ringkasan; kartu segmen (batang tipe 4dp, ikon, nama, detail, ⓘ, ⋮); blok Repeat; validasi.

Kontrol: TopBar Simpan; baris bawah + Segmen/+ Repeat/Preset; dialog "Buang perubahan?".

UI: kartu segmen min 72dp; baris bawah menempel; menu ⋮ (Naik/Turun/Duplikat/Hapus).

Navigasi: Simpan → S02; Preset → D02; Info → D11; kartu → D01.

S04 — Pra-start

Data: nama workout; strip + ringkasan; kartu status GPS (batang sinyal, angka akurasi, chip Siap/Lemah/Mencari); daftar segmen; pengaturan cepat.

Kontrol: MULAI (aktif bila izin lokasi ada — tanpa menunggu GPS).

UI: kartu GPS ~120dp; tombol MULAI tinggi 64dp titleM KAPITAL.

S05 — Layar Lari

Data (A–H): header (nama; ikon GPS + akurasi; toggle peta; chip DIJEDA); segmen (ikon, nama segmen, SEGMEN x/y, progress, sisa); banner; hero pace + target ≤/≥ + StatusBadge; metrik segmen; total; berikutnya; kontrol.

Kontrol: Lewati; Jeda/Lanjut (lingkaran besar); Stop tekan-tahan 2 dtk; Perpanjang; Daftar segmen; toggle peta; kembali (dialog).

UI: tidak bisa di-scroll; hero autosize; tombol Jeda 88dp aksen; Stop + ProgressRing; konten 55% saat pause.

State: WAITING_GPS, COUNTDOWN, RUNNING, PAUSED, GPS hilang, rencana selesai.

Navigasi: Stop → S06.

S06 — Simpan Sesi

Data: "Sesi siap disimpan"; jarak; Waktu/Pace/Segmen lulus; ResultStrip; banner rekor; Nama sesi; skala capek 1–10; Catatan + penghitung.

Kontrol: Simpan (primer) → simpan; Buang sesi (destruktif) → konfirmasi. Tanpa "Lewati".

UI: jarak displayL; footer menempel 2 tombol; skala capek 10 lingkaran 28dp.

State: "Menyimpan sesi…"; auto-recovery bila app mati.

S07 — Riwayat

Data: TopBar + pencarian; header bulan; item sesi (nama, tanggal/jam, jarak, waktu, pace /km, chip hasil N/M).

Kontrol: kartu → S08; ⋮ (Edit D03/Hapus D09).

State: skeleton; kosong; hasil pencarian kosong.

S08 — Detail Sesi

Data: TopBar (kembali; ikon peta toggle; ⋮ Edit/Export GPX/Kalibrasi/Hapus); judul + edit; tanggal/jam; jarak; metrik; ResultStrip; catatan; tab.

Tab Segmen: chip status; Batas; Jarak & Waktu; TARGET / AKTUAL / SELISIH; "Km di dalam segmen" (buka).

Tab Split km: tabel KM | WAKTU | PACE (/km) | SELISIH.

Tab Grafik: CH2 pace per km (batang); CH1 pace sepanjang jarak (garis, sumbu dibalik).

Tab Peta: polyline aksen + start/finish + batas segmen.

UI: tab garis bawah 3dp aksen; baris tabel 52dp.

S09 — Ringkasan Mingguan (Statistik ▸ Mingguan)

Data: navigator minggu; grid 2×3 kartu angka; daftar sesi minggu ini.

Grafik: CH3 jarak per hari; CH4 jarak 12 minggu; CH5 pace per minggu.

UI: kartu angka 84dp; grafik 160dp; hari/minggu terpilih disorot.

S10 — Rekor Pribadi (Statistik ▸ Rekor)

Data: 5 kartu rekor (waktu besar, pace, tanggal + sesi, piala); kartu "Belum ada"; daftar rekor terbaru; catatan.

UI: kartu 104dp; waktu numberXL.

Navigasi: kartu → S11.

S11 — Detail Rekor

Data: hero (waktu displayL, pace, tanggal + sesi → S08, "dari km x"); SegmentedControl Waktu/Pace; Top 10.

Grafik: CH6 best effort per sesi + garis rekor.

S12 — Pengaturan

Kelompok: TAMPILAN, VOICE, HITUNG MUNDUR, ALERT, TRACKING, DATA → S13, BANTUAN → S14, PENGEMBANG (debug) → S15/Katalog.

UI: tiap kelompok = RcCard + SectionHeader; kontrol SegmentedControl/RcSwitchRow/NumberStepper.

S13 — Cadangan & Data

Data: ringkasan (Sesi/Template/Ukuran); "Cadangan terakhir"; banner pengingat; SegmentedControl pengingat; Zona bahaya.

Kontrol: Cadangkan ke file; Pulihkan dari file; Hapus semua data (ketik "HAPUS").

UI: Zona bahaya = kartu border fail 1dp.

S14 — Panduan Baterai

Data: penjelasan; status optimasi; chip merek (gulir); kartu langkah.

Kontrol: Buka pengaturan baterai; Buka pengaturan aplikasi.

S15 — Simulator (debug) & Katalog Komponen

Data: workout; chip skenario; kecepatan 1x/10x/60x; panel log monospace.

Kontrol: Jalankan. Katalog menampilkan seluruh komponen UI.

10. Rumus & Aturan Penting

  • Jarak efektif: dEff = d × faktor kalibrasi (0,95–1,05).
  • Kalibrasi (F25): rawM = total / faktorLama; faktorBaru = clamp(sebenarnya / rawM, 0,95, 1,05). Tidak menumpuk.
  • Auto-pause (F26): speed < 0.6 m/s ≥ 3 dtk → jeda; lanjut saat bergerak. Tidak retroaktif.
  • Sample dibuang: akurasi > 20 m, timestamp tidak naik, kecepatan tersirat > 9 m/s.
  • GPS hilang: tanpa sample valid ≥ 10 dtk.
  • Segmentasi (F17): margin GPS min(target × 6 / jarak, 15) detik. Target maks lulus bila pace ≤ target; target min lulus bila pace ≥ target.
  • Rekor: dari bagian tercepat dalam sesi (window per jarak).

11. Catatan & Penyimpangan

  • S06 tidak auto-save: draft → final saat Simpan (auto-recovery saat app dibuka).
  • Mulai tanpa menunggu GPS; akurasi ditampilkan.
  • Target pace dua arah: ≤ Maks (lari) & ≥ Min (pemanasan/pendinginan/pemulihan).
  • D04/D06 tidak berbentuk dialog terpisah.
