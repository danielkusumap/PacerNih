S03 Editor Workout
LARI
Kegunaan
Bagian inti latihan: stable run, interval cepat, atau tempo.
Kapan dipakai
Setiap bagian yang ingin diukur dengan target.
Contoh pengaturan
Stable: 5 km, ≤ 7:00. Interval: 400 m, ≤ 6:00 diulang 3×.
Perilaku di aplikasi
Rata-rata segmen harus memenuhi target agar lulus; alert terlalu lambat/cepat aktif.
Tips
Segmen 200 m bisa BORDERLINE karena error GPS.
